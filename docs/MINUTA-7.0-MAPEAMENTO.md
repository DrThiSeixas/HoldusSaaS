# Holdus — Mapeamento da Minuta 7.0
## Acordo de Quotistas — Célula Destino

**Código:** `DESTINO.ACORDO_QUOTISTAS.V1`

---

## 1. Posição na Arquitetura

```
1. Contrato social da Destino     → cria a célula
2. Instrumento de doação           → transfere as quotas
3. Alteração contratual            → reflete a nova titularidade
4. Acordo de Quotistas             → regula o sistema  ← ESTA PEÇA
```

---

## 2. Núcleos obrigatórios

| Núcleo | Pergunta que responde |
|--------|-----------------------|
| Vinculação | Para que serve este acordo? |

| Controvérsias | Foro, arbitragem ou mediação |

## 3. Módulos Parametrizáveis (4 escolhas obrigatórias)

### MOD-A: Regime de voto (Cláusula 3)
| Módulo | Descrição |
|--------|-----------|
| A — Sem usufruto | Quotista vota direto |
| B — Usufrutuário vota | Voto do usufrutuário enquanto perdurar |
| C — Nu-proprietário vota | Voto do nu-proprietário |
| D — Regime misto | Ordinário = um, extraordinário = conjunto |

### MOD-B: Direitos econômicos (Cláusula 4)
| Opção | Descrição |
|-------|-----------|
| 1 | Frutos 100% do usufrutuário |
| 2 | Frutos 100% do nu-proprietário |
| 3 | Repartição personalizada |

### MOD-C: Quórum de governança (Cláusula 5)
| Opção | Descrição |
|-------|-----------|
| Unanimidade | Todas as matérias sensíveis |
| Maioria qualificada | 75% ou 2/3 |
| Personalizado | Por matéria |

### MOD-D: Solução de controvérsias (Cláusula 14)
| Opção | Descrição |
|-------|-----------|
| Foro | Comarca eleita |
| Arbitragem | Câmara arbitral |
| Mediação + foro | Mediação prévia obrigatória |

## 6. Evolução prevista (V1.1)

- Voto e usufruto refinado por matéria
- Matrizes familiares (casal+filhos, família recomposta, descendente incapaz)
- Sanções graduadas (advertência → multa → suspensão → obrigação de vender)
- Valuation (patrimonial, balanço de determinação, fórmula contratual)
- Integração com contrato social + alteração de doação
